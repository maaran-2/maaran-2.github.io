# CV Study Hub — GitHub Pages Website

This is a static website for your two Computer Vision practical PDFs.

## Files
- `index.html` — the responsive website page
- `files/cv-programs-01-07.pdf` — uploaded PDF for programs 01–07
- `files/cv-programs-08-15.pdf` — uploaded PDF for programs 08–15

## Publish to your existing GitHub Pages site
1. Open https://github.com/maaran-parotta/maaran-parotta.github.io
2. Make a backup of the current files before replacing anything.
3. Upload `index.html` to the repository root.
4. Upload the whole `files` folder with both PDFs inside it. If GitHub's web uploader does not preserve folders, create `files/` first and upload each PDF into that folder.
5. Commit the changes to the branch configured for GitHub Pages (usually `main`).
6. Wait a few minutes, then visit https://maaran-parotta.github.io and refresh.

## Test locally
Open `index.html` in a browser. To test the PDF links, keep the `files` folder beside `index.html`.

## Updating the PDFs
Keep the filenames exactly as shown above, or update the two PDF links in `index.html` if you rename the files.
